# Project starter files

Copy `project_readme_template.md` into your team branch and fill it before
implementing a controller. The template forces the command contract, state
machine, metrics and limitations to be explicit.

Recommended branch sequence:

```bash
git switch -c project-team-name
cp exercises/projects/project_readme_template.md projects/team-name.md
git add projects/team-name.md
git commit -m "Define project interface and acceptance metric"
```

Keep generated `build/`, `install/`, `log/`, `frames.pdf` and temporary plots out
of the source package unless the team deliberately submits a small final figure.
